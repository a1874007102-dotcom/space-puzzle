# 儿童太空益智乐园 · 设计文档

日期：2026-08-07
状态：已确认（2026-08-07，逐节评审通过）

## 1. 概述

一款面向 9-12 岁儿童的太空探险主题益智网页游戏。孩子通过"星球地图"进入 5 款小游戏，在闯关中获得星星与积分，形成持续的目标感。家长可通过隐藏入口查看进度、设置每日限时并重置存档。

- 目标用户：9-12 岁儿童（主要玩家），家长（监督与设置）
- 平台：现代浏览器（桌面 / 平板 / 手机竖屏）
- 技术：纯 HTML/CSS/JavaScript（ES Modules），零第三方依赖、零构建
- 语言：中文界面；拼单词游戏内含英语与中文两套词库
- 运行方式：本地双击或静态托管（GitHub Pages）

## 2. 需求清单

1. 门户：太空星球地图，5 颗星球对应 5 款游戏
2. 小游戏：算术速算、记忆翻牌、找规律、拼单词（英/中）、逻辑推理
3. 进度系统：星星 + 积分，本地存档（无账号）
4. 音频：Web Audio 合成音效与背景音乐，可静音
5. 家长区：隐藏入口，进度/用时查看、每日限时、静音、重置存档
6. 发布：GitHub Pages 静态托管，相对路径兼容子路径
7. 响应式：桌面、平板、手机竖屏均可用

## 3. 架构与目录结构

项目根目录：`superpowers-game/`

```
superpowers-game/
├── index.html              # 门户：星球地图
├── css/
│   └── base.css            # 全局样式、太空主题变量（单一入口）
├── js/
│   ├── core/               # 共享核心，所有游戏复用
│   │   ├── storage.js      # 存档（localStorage，含损坏降级）
│   │   ├── audio.js        # Web Audio 合成音效 + 背景音乐
│   │   ├── scoring.js      # 星星/积分结算规则
│   │   └── ui.js           # 共享组件：弹窗、倒计时、结算页
│   └── games/              # 每个游戏一个独立文件夹
│       ├── arithmetic/     # 算术速算
│       ├── memory/         # 记忆翻牌
│       ├── patterns/       # 找规律
│       ├── spelling/       # 拼单词（英/中词库）
│       └── logic/          # 逻辑推理
├── assets/                 # SVG 图形、词库 JSON（零外部依赖）
├── tests/                  # 规则引擎纯函数测试
└── docs/                   # 设计文档、发布说明
```

关键决策：

- **ES Modules + 静态文件，零构建**：浏览器原生 `type="module"` 加载，GitHub Pages 直接托管。
- **每款游戏是独立单元**：只通过核心 API（存档/音效/计分）与门户交互，游戏之间零耦合；新增游戏 = 新建文件夹 + 门户加星球入口。
- **规则与界面分离**：出题、判分、星级结算写成纯函数，渲染层只负责展示，便于测试。
- **主题单入口**：`base.css` 定义配色/字体/圆角/动效变量，各游戏只引用变量，保证风格统一。

## 4. 门户与导航

### 星球地图

- 主界面为太空场景：5 颗星球代表 5 款游戏，围绕中央飞船（吉祥物）分布。
- 每颗星球显示：游戏图标、已获星星（如 ★★★☆☆）、未解锁时显示所需星星数。
- 解锁规则：算术速算默认开放；每累计 6 颗星星解锁下一颗星球。
- 顶部常驻信息栏：总星星数、总积分、静音按钮、家长入口。

### 导航流程

- 门户 → 点星球 → 游戏页（全屏）→ 结算页 → 返回门户。
- 结算页：本次得分、获得的星星、随机太空主题鼓励语；按钮为"再玩一次 / 返回地图"。
- 每款游戏 3 个难度：新手 → 探险家 → 舰长，达到条件解锁更高难度。

### 主题与交互规范

- 深蓝星空背景 + 动态星星粒子 + 卡通 SVG 星球；图形全部用 SVG/CSS 绘制，无外部图片。
- 按钮大而圆润、触控友好（最小 48px），动画轻快（翻转、缩放、粒子爆发）。
- 响应式：移动端优先设计，桌面、平板、手机竖屏均可用。

## 5. 核心系统

### 存档模型

localStorage 键名：`superpowers-save-v1`

```json
{
  "stars": 12,
  "points": 340,
  "games": {
    "arithmetic": {
      "levels": { "1": 3, "2": 1 },
      "bestScore": 28,
      "plays": 15,
      "lastPlayedAt": "2026-08-07T10:00:00Z"
    }
  },
  "settings": {
    "muted": false,
    "dailyLimitMinutes": 30
  },
  "usage": { "2026-08-07": 12 }
}
```

- 每局结算后，星星按"历史最高"更新，积分累加。
- 读写全部收敛在 `storage.js`；数据损坏或 localStorage 不可用时，降级为内存存档并提示，不崩溃。

### 星星与解锁规则

- 每局按表现给 0-3 星。
- 难度解锁：难度 2 需该游戏累计 2 星，难度 3 需累计 4 星。
- 星球解锁：累计 6 星解锁下一颗（算术速算默认开放）。

### 音频（Web Audio 合成）

- 音效：点击、答对（上行琶音）、答错（柔和低音）、翻牌、通关（号角式和弦），全部代码合成。
- 背景音乐：轻量太空风循环旋律，可静音，状态存入设置。
- 浏览器自动播放限制：首次用户交互时才初始化 AudioContext。

### 家长区

- 入口：连点左上角飞船图标 5 次。
- 验证：4 位数 PIN（默认 0000，首次进入强制修改）。
- 功能：查看各游戏进度与总用时、按天查看游玩时长、设置每日限时、静音开关、重置存档（二次确认）。

### 每日限时

- 达到限额后弹出友好全屏页"该休息啦，去喝口水吧 ☄️"，当天不再放行。
- 家长可在家长区调整限额。

### 错误处理

- 存档损坏/不可用 → 内存存档降级 + 提示。
- 音频不可用 → 静音降级。
- 题库加载失败 → 重试界面。
- 判分逻辑纯函数化，便于测试与回归。

## 6. 小游戏规则

所有游戏共用：3 个难度、统一结算页、统一出题/判分纯函数。

### 6.1 算术速算

- 新手：20 以内加减法；探险家：100 以内加减 + 九九乘法；舰长：混合四则运算（含括号）。
- 每局 60 秒，题目 4 选 1；答对 +10 分并累计连击（连击 ×1.5 加成），答错断连击。
- 星星：≥60% 正确率 1 星，≥80% 2 星，≥95% 且 ≥15 题 3 星。

### 6.2 记忆翻牌

- 新手 6 对（4×3 格）、探险家 8 对（4×4）、舰长 12 对（6×4）。
- 配对内容随难度升级：符号 → 数字/字母 → 算式与结果配对。
- 计分 = 基础分（对数越多越高）− 超步数扣分；限定步数内完成才有星，步数越少星越多。

### 6.3 找规律

- 每轮 10 题，展示序列选"下一个"。
- 新手：图形/颜色循环规律；探险家：等差/等比数列；舰长：混合递推（如 ×2−1）。
- 星星：≥60% 1 星，≥80% 2 星，全对 3 星。

### 6.4 拼单词（英/中双语）

- 英语：看图 + 发音提示，从乱序字母池点选拼词；词库按 3-4 年级、5-6 年级分两档。
- 中文：看释义，点选汉字拼词语/成语；词库按常用度分两档。
- 每轮 10 词；拼错时高亮正确字母，给第二次机会。
- 星星：≥60% 1 星，≥80% 2 星，全对 3 星。

### 6.5 逻辑推理

- 题型：条件推理（如"A 比 B 高，C 比 A 矮，谁最高？"）、真假判断、类比推理。
- 新手 2 条条件、探险家 3 条、舰长 4 条（组合题）。
- 每轮 10 题，答对率计星。
- 纯文字题，不做复杂拖拽。

## 7. 测试策略

- 出题/判分/星级结算为纯函数，用零依赖 Node 脚本断言（`node tests/run-tests.js`）。
- 每款游戏一份手动验收清单：正常流程、答错流程、中途退出、刷新恢复、家长区各功能。
- 桌面 + 手机/平板各过一遍（触控目标 ≥48px、竖屏布局）。

## 8. 发布

- 项目自带 git 仓库；全部相对路径，GitHub Pages 子路径（`/仓库名/`）下正常加载。
- `docs/publishing.md` 记录三步：推送到 GitHub → 仓库设置开启 Pages → 访问地址。
- 本地运行：双击 `index.html`，或 `python -m http.server` / `npx serve`。

## 9. 里程碑

- **M1 地基**：核心系统（存档/计分/音频/UI 组件）+ 门户星球地图 + 家长区。
- **M2 前三款**：算术速算、记忆翻牌、找规律，走通完整流程与结算。
- **M3 后两款**：拼单词（双词库）、逻辑推理。
- **M4 打磨发布**：响应式收尾、音效润色、测试全绿、发布文档。

每个里程碑完成即可试玩验证。

## 10. 非目标（YAGNI）

- 不做账号与云端同步。
- 不做 PWA 安装（第二版可选）。
- 不做多人对战与社交功能。
- 不引入第三方音频/图片素材。
- 不做服务端与数据库。
